# Dayly — финансовый помощник студента

Показывает, сколько можно потратить сегодня, чтобы денег хватило до следующего поступления. Данные хранятся только в браузере (`localStorage`), без сервера и регистрации.

**Открыть:** https://egoricon.github.io/Dayly/ — на телефоне «Поделиться» → «На экран Домой» (iPhone) или «Установить приложение» (Android). Сайт обновляется сам после каждого пуша в `main` (`.github/workflows/pages.yml`).

## Запуск

Нужен Node.js 20 или новее. Одна команда:

```bash
npm start
```

При первом запуске она сама ставит зависимости (`npm install`), потом поднимает dev-сервер. Открыть http://localhost:5173.

С телефона в той же Wi-Fi-сети: `npm start -- --host` и адрес `Network:` из вывода.

## Установить на телефон

Приложение — PWA. Для установки на главный экран нужна сборка:

```bash
npm run build
npm run preview -- --host
```

На телефоне открыть адрес `Network:` и выбрать «На экран „Домой“» (Safari) или «Установить приложение» (Chrome). После первого открытия приложение работает без сети. Установленное на главный экран приложение браузер не очищает, поэтому данные надёжнее хранятся именно так.

> Service worker и установка работают на `localhost` и по HTTPS. По адресу вида `http://192.168.…` телефон откроет приложение, но офлайн-режима и установки не будет.

## Команды

| Команда | Что делает |
|---|---|
| `npm start` | ставит зависимости при первом запуске и запускает dev-сервер Vite |
| `npm test` | юнит-тесты расчёта и данных (Vitest) |
| `npm run e2e` | e2e-проверка критериев MVP и обновлений в Chromium (Playwright): собирает приложение и открывает его |
| `npm run typecheck` | проверка типов (`tsc --noEmit`) |
| `npm run build` | проверка типов и сборка в `dist/` |
| `npm run preview` | раздаёт собранный `dist/` |

Для `npm run e2e` нужен Chromium для Playwright 1.56.1 (`npx playwright install chromium`, если его ещё нет). Профиль браузера пишется в `test-results/`; на сетевом диске укажите локальную папку: `DAYLY_E2E_OUTPUT=/tmp/dayly-e2e npm run e2e`.

## Устройство

- `src/domain/` — расчёт дневного лимита, плановых поступлений и платежей, истории, копилки (банки, движения, прогноз наполнения). Чистые функции без UI и хранилища (`calculateBudget`).
- `src/appData.ts` — все изменения данных: траты и доходы, подтверждения, «Положить» и «Забрать», округление, настройки, сверка баланса, тема.
- `src/storage.ts`, `src/uiState.ts` — `localStorage`: данные под ключом `dayly:data`, состояние интерфейса под `dayly:ui`.
- `src/screens/` — первая настройка, главная, «Копилка», история, «Финансы» с календарём, настройки, «Как считается», «Как устроен Dayly». `src/components/` — кольцо, свинка, шторки, строка операции, клавиатура, календарь, подсказки, таб-бар. Редко открываемые экраны грузятся по требованию, service worker кэширует и их.
- `public/` — манифест, иконки и service worker (`sw.js`, написан вручную).
- `e2e/` — проверка критериев готовности MVP и обновлений 1–2. `scripts/start.mjs` — команда `npm start`.

Решения и модель данных — в `CLAUDE.md`, полная карта проекта — в `PROJECT_MAP.md`.
